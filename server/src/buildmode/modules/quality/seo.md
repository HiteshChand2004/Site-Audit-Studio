title: Search engine basics
---
Every page: a unique title of 10–60 characters (page topic first, brand last), a unique meta description of 50–160 characters,
exactly one h1, headings in order without skipped levels, a canonical link, Open Graph title / description / image,
<html lang>, descriptive link text, and alt text on every meaningful image (alt="" on decorative ones). Provide sitemap.xml and
robots.txt that lists it. Clean, readable URL paths.
