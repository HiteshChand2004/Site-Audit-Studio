The project folder holds only the stack's empty scaffold. There is no existing design to respect: the design direction in the
brief is the source of truth. Create every page, component and asset the brief needs, with local files for everything.
There are no photos: follow "Images without photos" in the visual craft guide, and list every image placeholder in finish.
