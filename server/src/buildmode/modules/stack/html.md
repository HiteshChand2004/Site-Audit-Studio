title: Plain HTML, CSS and a little JavaScript
---
Write semantic, standards-valid HTML5: one file per page (index.html, about/index.html …), a shared stylesheet in css/, small
progressive-enhancement scripts in js/ only where interaction needs them (menus, tabs, accordions), loaded with defer. The site
must work and read well with JavaScript off. No frameworks or CDNs: everything is a local file. Relative links between pages.
