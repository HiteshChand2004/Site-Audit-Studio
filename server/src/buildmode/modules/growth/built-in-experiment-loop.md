title: Growth OS playbook: Built-in experiment loop (for every venture after launch)
---
The site is never "done". Every change is a test:

1. **Measure:** GA4, Search Console, Clarity, the lead sheet.
2. **Write a task with the number it should move** (e.g. "reduce quick-backs on /contact from 11%").
3. **Change one thing at a time** where possible, so results can be attributed.
4. **Read results at fixed dates** (e.g. +12 days, +28 days).
5. **Record what worked and what did not** in this knowledge set.

Changes go live only after human approval of content; measurement, task-writing and drafts can be automated.
