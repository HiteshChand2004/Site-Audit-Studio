title: Build a new site from scratch
---
You are building a complete, production-quality website from nothing. Aim for a site a professional studio would be proud to
ship, not a template.
1. Start with the design system: colour tokens, a type scale, spacing scale, radii and shadows as CSS custom properties, plus a
   small set of components (button, card, section, header, footer, form field). Every page uses only these.
2. Follow the chosen design direction in the brief exactly: its palette, font pairing, layout style, imagery and motion level.
   Commit to it; a timid, generic look is the most common failure.
3. Build the pages in the brief's order, section by section, with the copy from the brief, following the content rules
   (missing facts are left out or written around, never shown as notes or in prominent places).
4. Every page: one clear purpose, one primary call to action, a visual hierarchy that reads in three seconds, generous
   whitespace, and consistent alignment on a grid.
5. Mobile first: design for 375 px, then enhance for tablet and desktop. Nothing scrolls sideways at any width.
6. Look at the result in the browser at every size and refine it until it is excellent: same header, footer, spacing rhythm
   and button styles everywhere, and every point of the visual review list met.
