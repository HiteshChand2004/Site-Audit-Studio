title: A targeted change to an existing site
---
You are making a specific, limited change. Precision matters more than ambition.
- Change only what the brief's requirements name. Everything else must stay byte-for-byte the same where possible.
- Reuse the site's existing classes, components, colours and fonts for anything new, so the change looks native.
- Keep existing class names, ids and data attributes; other code may depend on them.
- If a requirement can only be met by touching something outside its scope, do the smallest such change and say so in finish.
